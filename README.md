# ImgVaguer

图片加密混淆与还原工具。支持**密文混淆**（输出噪声状图像，可见像素分载荷级 / 像素级两种布局）与**覆盖合成**（多图层视觉遮盖）两种混淆方式，提供无口令 / 口令 / 密钥文件三种保护方式，全部处理在本地完成，还原逐位无损。

## 功能特性

- **两种混淆方式**
  - 密文混淆：输出噪声状图像，可见像素有两种布局
    - **载荷级**（默认，推荐）：原图以**原始文件字节**经 ChaCha20 加密存入 PNG 私有数据块，解密即还原原文件——格式、清晰度与体积都与输入一致；可见像素只是密钥化的装饰噪声，尺寸独立于原图，故输出通常只比原文件大百分之几
    - **像素级**：可见像素即密文，经「通道置换 → 异或流 → S 盒替换 → 加性噪声 → 行列移位 → 块内置换 → 块间置换 → 全局像素置换」逐像素可逆变换，多轮可叠加，全程双射、逐位还原；解密由像素还原为 PNG
  - 覆盖合成：最多 8 层混淆图叠放遮盖，目标图层位可选；原图以原始文件字节经 ChaCha20 加密存入 PNG 私有数据块
- **还原即原文件**：载荷级密文混淆、覆盖合成与多图合并的还原结果就是原始文件（沿用原文件名与格式），多图合并会逐一展开
- **三种保护方式**：无（种子内嵌，持图即还原）/ 口令（PBKDF2-SHA256）/ 密钥文件（`.ivkey`，凭文件还原）
- **凭据派生分档**：口令走 PBKDF2-SHA256 迭代拉伸；密钥文件种子与内嵌种子为 256 位全熵，走 HKDF-SHA256——迭代拉伸对高熵密钥没有强度增益，只会平白耗时
- **逐图随机 IV**：每次加密生成独立随机 salt/IV 并写入 nonce 域，同一密钥下的不同图像（含整批批量加密）绝不共享 ChaCha20 密钥流
- **密文认证**：HMAC-SHA256 覆盖公开前导、加密元数据与可见像素；口令/密钥错误或文件被篡改（含像素改动）一律明确报错，绝不输出乱图
- **无损还原**：载荷级布局逐字节还原原文件；像素级布局经内置 PNG 解码器逐位还原，不依赖 canvas 的色彩/预乘处理，含透明通道亦精确可校验
- **体积优化**：编码启用自适应行滤波（PNG 压缩能力的主要来源），全不透明图像按 RGB 编码省去 alpha 通道；装饰图的尺寸与块边长按载荷体积反解，使输出与原文件相当；压缩级别取压缩率与耗时的曲线拐点
- **批量处理**：多图同参数批量加解密，结果打包 ZIP（含密钥文件）；合并张数（1–12）与单张像素上限可在设置中调整
- **按需解码**：选图只读取尺寸，位图推迟到加密时才解码，批量载入大图不会因内存不足而失败
- **多图合并**：一张输出打包整批原文件，解密时逐一还原（不含遮盖图）；三种保护方式均可用，合并标志随元数据加密
- **结果面板**：每次执行生成一批结果，可翻阅历史批次、删除某批、一键打包该批（含密钥文件）；关闭程序即清空
- **终端视图**：精简 / 详情两档，详情展示加密解密的步骤、参数与方法，可一键清屏
- **体验细节**：顶栏「加密 / 解密」页签、拖拽载入、堆叠预览（滚轮/箭头切换、点击放大）、混淆层拖曳排序、主题化浮动提示、参数本地记忆、默认口令/混淆图/层数上限、内置分类文档
- **安全原语**：ChaCha20（RFC 8439 测试向量校验）、PBKDF2-SHA256（RFC 7914 向量校验）、HKDF-SHA256、HMAC-SHA256（RFC 4231 向量校验）

## 安全性

- **无保护**：混淆而非加密，持图即可还原，仅降低随手查看的可见度。
- **口令保护**：PBKDF2-SHA256 派生 + ChaCha20 密钥流加密，未被口令保护的内容无法还原；强度取决于口令熵与迭代次数。
- **密钥文件保护**：256 位全熵密钥，密钥文件不泄露时等效于真加密（AES 类）强度。
- **逐图随机 IV**：每次加密生成独立随机 salt/IV 并写入 nonce 域，同一密钥下的不同图像（含整批批量加密）绝不共享 ChaCha20 密钥流；像素级布局下像素先经密钥流异或再置换，抗拼图/统计攻击。
- **密文认证**：HMAC-SHA256 覆盖公开前导、加密元数据与可见像素，口令/密钥错误或文件被篡改（含像素改动）一律拒绝，绝不输出乱图。
- **元数据加密 / 去指纹**：公开字段仅有引导密钥派生所需的 version/salt/迭代数/随机种子；模式、布局、保护方式、参数、原图尺寸与载荷全部加密存放，文件中不含工具品牌标识。载荷级布局的可见图尺寸独立于原图，连带原图尺寸也不泄露。
- **保护方式不可区分**：三种保护方式统一为「字节凭据 → 主密钥」，公开 seed 恒为等长随机，单看文件无法分辨其保护方式。
- **载荷与像素同等受保护**：载荷级布局下原始文件整块受密钥流加密与同一条 HMAC 保护；篡改元数据标志位同样会被拒绝。
- **全程离线**：图像、口令与密钥文件不经过任何网络传输。

> 文件仍含一个私有数据块，可被专业分析判断为"经本工具处理"，但不泄露内容与参数；不提供隐写伪装或不可否认性。

## 技术栈

TypeScript · Vue 3 (Composition API) · Vite · Vitest · fflate · Electron（桌面打包）
核心算法层（`src/core/`）为无 DOM 依赖的纯 TS 实现，全部经往返一致性单测覆盖。

## 使用简述

1. **加密**：左栏顶部选「加密」→ 拖入目标图（可多选）→ 选择混淆方式与保护方式（可在「输入」区底部勾选多图合并）→ 调整参数 → `[ 执行加密 ]` → 结果区下载。密文混淆可选「载荷级（体积小）」或「像素级（可见像素即密文）」布局；密钥文件保护时，结果区会生成 `.ivkey` 供手动下载。
2. **解密**：左栏顶部切到「解密」→ 拖入本工具生成的 PNG → 按需输入口令或拖入 `.ivkey` → `[ 执行解密 ]`。混淆方式、布局与全部参数自动从图像数据块读取；载荷级布局直接还原出原始文件，多图合并会逐一展开为全部原文件。
3. 更详细的说明见应用内「设置 → 打开使用文档」。

## 注意事项

- 输出 PNG 内含私有数据块；经其他编辑器另存/压缩/转格式会丢失该数据块，导致无法还原。
- 口令与密钥文件一旦丢失即无法还原，请分开妥善保管。密钥文件为多行文本（含创建时间与密钥指纹），实质是一枚 256 位随机种子。
- 默认保护方式为**口令**；「无（种子内嵌）」持图即可还原，仅适用于防君子场景。
- 「默认口令」以明文存于 localStorage，公共设备请勿使用。
- 载荷级布局还原的是原始文件本身，原文件的元数据（EXIF / GPS 等）也随之保存在加密载荷中；如需去除元数据，请先清理原图再加密，或改用像素级布局。
- 多图合并的输出体积约等于各原文件之和（原文件多已压缩，二次压缩收益有限），张数越多输出越大；张数与单张像素上限可在设置中调整。
- **本版加密与解密配套**：请使用同一版本加密与解密，版本不符时会明确提示，不会静默产出错误结果。

# ImgVaguer

图片加密混淆与还原工具。支持**密文混淆**（像素级密钥化可逆变换，输出噪声状图像）与**覆盖合成**（多图层视觉遮盖，原图加密内嵌）两种混淆方式，提供无口令 / 口令 / 密钥文件三种保护方式，全部处理在本地完成，还原逐位无损。

## 功能特性

- **两种混淆方式**
  - 密文混淆：通道置换 → 异或流 → S 盒替换 → 加性噪声 → 行列移位 → 块内置换 → 块间置换 → 全局像素置换，多轮可叠加，全程双射、逐位还原
  - 覆盖合成：最多 8 层混淆图叠放遮盖，目标图层位可选；原图经 zlib + ChaCha20 加密存入 PNG 私有数据块
- **三种保护方式**：无（种子内嵌，持图即还原）/ 口令（PBKDF2-SHA256）/ 密钥文件（`.ivkey`，凭文件还原）
- **逐图随机 IV**：每次加密生成独立随机 salt/IV 并写入 nonce 域，同一密钥下的不同图像（含整批批量加密）绝不共享 ChaCha20 密钥流
- **密文认证**：HMAC-SHA256 覆盖公开前导、加密元数据与密文像素；口令/密钥错误或文件被篡改（含像素改动）一律明确报错，绝不输出乱图
- **无损解码**：解密经内置 PNG 解码器逐位还原，不依赖 canvas 的色彩/预乘处理，含透明通道亦精确可校验
- **批量处理**：多图同参数批量加解密，结果打包 ZIP（含密钥文件）
- **结果面板**：每次执行生成一批结果，可翻阅历史批次、删除某批、一键打包该批（含密钥文件）；关闭程序即清空
- **终端视图**：精简 / 详情两档，详情展示加密解密的步骤、参数与方法，可一键清屏
- **体验细节**：拖拽载入、堆叠预览（滚轮/箭头切换、点击放大）、混淆层拖曳排序、参数本地记忆、默认口令/混淆图/层数上限、内置分类文档
- **安全原语**：ChaCha20（RFC 8439 测试向量校验）、PBKDF2-SHA256、HMAC-SHA256

## 安全性

- **无保护**：混淆而非加密，持图即可还原，仅降低随手查看的可见度。
- **口令保护**：PBKDF2-SHA256 派生 + ChaCha20 密钥流加密，未被口令保护的内容无法还原；强度取决于口令熵与迭代次数。
- **密钥文件保护**：256 位全熵密钥，密钥文件不泄露时等效于真加密（AES 类）强度。
- **逐图随机 IV**：像素先经密钥流异或再置换，抗拼图/统计攻击；同一密钥下多图不共享密钥流。
- **密文认证**：HMAC-SHA256 覆盖公开前导、加密元数据与密文像素，口令/密钥错误或文件被篡改（含像素改动）一律拒绝，绝不输出乱图。
- **元数据加密 / 去指纹**：公开字段仅有引导密钥派生所需的 version/salt/迭代数/随机种子；模式、保护方式、参数、原图尺寸与载荷全部加密存放，文件中不含工具品牌标识。
- **保护方式不可区分**：三种保护方式统一为「字节凭据 → PBKDF2 → 主密钥」，公开 seed 恒为等长随机，单看文件无法分辨其保护方式。
- **全程离线**：图像、口令与密钥文件不经过任何网络传输。

> 文件仍含一个私有数据块，可被专业分析判断为"经本工具处理"，但不泄露内容与参数；不提供隐写伪装或不可否认性。

## 技术栈

TypeScript · Vue 3 (Composition API) · Vite · Vitest · fflate · Electron（桌面打包）
核心算法层（`src/core/`）为无 DOM 依赖的纯 TS 实现，全部经往返一致性单测覆盖。

## 运行与构建

```bash
# 安装依赖
npm install

# 开发模式（热更新，默认 http://localhost:5173）
npm run dev

# 单元测试（核心算法往返一致性）
npm test

# 类型检查
npm run typecheck

# Web 生产构建（输出 dist/）
npm run build

# 打包 Windows 便携版 exe（输出 release/）
npm run dist:win
```

## 使用简述

1. **加密**：拖入目标图（可多选）→ 选择混淆方式与保护方式 → 调整参数 → `[ 执行加密 ]` → 结果区下载。密钥文件保护时，结果区会生成 `.ivkey` 供手动下载。
2. **解密**：切到「解密」→ 拖入本工具生成的 PNG → 按需输入口令或拖入 `.ivkey` → `[ 执行解密 ]`。混淆方式与全部参数自动从图像数据块读取。
3. 更详细的说明见应用内「设置 → 打开使用文档」。

## 注意事项

- 输出 PNG 内含私有数据块；经其他编辑器另存/压缩/转格式会丢失该数据块，导致无法还原。
- 口令与密钥文件一旦丢失即无法还原，请分开妥善保管。
- 默认保护方式为**口令**；「无（种子内嵌）」持图即可还原，仅适用于防君子场景。
- 「默认口令」以明文存于 localStorage，公共设备请勿使用。

## 项目结构

```
src/
├─ core/        # 纯 TS 算法层：chacha / kdf / scramble / overlay / png / header / keyfile
├─ services/    # 编排引擎、图像 IO、用户动作
├─ stores/      # 响应式会话状态 + localStorage 设置持久化
├─ components/  # TUI 组件（拖放区、参数面板、堆叠预览、设置/文档面板等）
└─ styles/      # 复古 TUI 主题
electron/       # Electron 壳（便携 exe 打包）
tests/          # Vitest 核心算法单测
```
